# Sample proposals (made up)

Invented drywall proposals for building and testing proposal intake. Every company, person, project,
and number here is fictional. Real proposals never go in this folder or in git.

| File | What it exercises |
|---|---|
| `summit-drywall-rev1.txt` / `.pdf` | Clean itemized proposal: breakouts that tie, alternates, allowance, inclusions, exclusions, terms |
| `summit-drywall-rev2.txt` | Revision 2 of the same proposal: supersedes rev 1 |
| `coastal-interiors-email.txt` | Email quote with problems: math does not tie, an option inside the total, short validity, escalation, 30% mobilization, bond excluded, no drawing basis |
| `bayline-walls-lump-sum.txt` | Lump-sum budget proposal: no breakouts, budget pricing |
